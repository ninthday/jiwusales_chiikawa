# 技術棧 (Tech Stack)

## 前端開發 (Frontend)
- **程式語言**：JavaScript (Vanilla JS)。
- **標記與樣式**：HTML5, CSS3。
- **排版技術**：Flexbox 與 CSS Grid 用於響應式佈局。

## 資料與 API (Data & APIs)
- **外部資料源**：Google Sheets API (透過 gviz/tq 端點)。
- **本地儲存**：Web LocalStorage API 用於儲存使用者的收藏進度。

## 基礎設施 (Infrastructure)
- **託管平台**：GitHub Pages。
- **預覽與分享**：Open Graph (OG) 標籤優化社群分享。
